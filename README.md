# Тестирование интернет-магазина

## 📌 Описание проекта

В данном репозитории представлен проект по ручному тестированию веб-приложения интернет-магазина.

Тестируемое приложение:
https://products-store.hexlet.app/

Цель проекта — продемонстрировать процесс тестирования веб-приложения и навыки ручного тестирования, включая:

* анализ требований
* разработку тестовой документации
* проведение тестирования
* оформление баг-репортов

---

# Цели тестирования

Основные цели тестирования:

* проверить корректность работы функционала интернет-магазина
* выявить дефекты в работе приложения
* проверить основные пользовательские сценарии

---

# Функциональность тестируемого приложения

Интернет-магазин предоставляет следующие возможности:

* просмотр каталога товаров
* поиск товаров
* фильтрация товаров
* просмотр карточки товара
* добавление товаров в корзину
* просмотр корзины
* переключение языка интерфейса
